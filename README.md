# 🎬 CineSearch

## 📋 About
This project is built to learn core JavaScript concepts 
through a real-world movie search application using TMDB API.

## ✨ Features
- 🔥 Trending Movies
- ⭐ Top Rated Movies  
- 🗓️ Upcoming Movies
- 🔍 Movie Search
- ❤️ Favorites
- 📌 Watchlist
- 🎬 Movie Details Page

## 🛠️ Tech Stack
- Vanilla JavaScript (ES6+)
- HTML5 & CSS3
- TMDB API

## 🧠 JS Concepts Covered
- 🔗 **Fetch API** — TMDB se data fetch karna
- 🤝 **Promises & Async/Await** — Async data handle karna
- 🛡️ **Try/Catch** — Error handling
- 🌐 **DOM Manipulation** — Dynamic UI banana
- 🖱️ **DOM Events** — User interactions handle karna
- 🎯 **Event Delegation** — Efficient event handling
- 💾 **LocalStorage** — Favorites & Watchlist save karna
- 📦 **ES6 Modules** — Import/Export
- 🔧 **URLSearchParams** — URL se data nikalna
